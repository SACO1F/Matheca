Matheca

机器先写，你落笔定稿。

面向高中数学备课的本地题库。拍照、相册或 PDF 导入，识别结果只存成待校对草稿；你对照原图改完，再按知识点分类、选题组卷，导出 A4 PDF 与 Word。

下载 Windows 版 下载 Android 版
  • Windows x64
  • Android 8.0+
  • 题库保存在本机
  • 整理与导出可离线

它适合谁

写给谁
高中数学老师。备课、周测、月考，同一道题会反复用上几年。
什么时候用
手上是拍照的讲义、扫描的试卷、别人的 PDF，而题库还散在一个文件夹里。
换来什么
一份能改、能备份的本地题库，和一张能直接印的 A4 卷子。

同一份题库上，
把九件事做完

AI 自主识别需联网

接 OpenAI 兼容的视觉接口，服务商、地址、Key 与模型都由你填。同一批连续照片跨页续题，失败可重试，成功结果缓存，你改过的内容不会被再次覆盖。

题目录入

拍照、相册、PDF、手动录题；桌面另加截图、剪贴板与拖放。

对照原图校对

左原来稿，右编题干。手机改完返回，仍停在原来的筛选与滚动位置。

题库整理

年级、知识点、题型、难度、关键词、收藏、校对状态，七项筛选叠加使用。正文、公式与插图原样显示。

题集组卷

选题、排序、移除；标题、说明、考试时间、满分、每题留白与题前分页逐项设置。

导出 PDF 与 Word

A4 版式，选择题选项单独排版。Word 里的公式是图片，Word／WPS 可能重新分页。

手机接着干

同局域网扫码配对，电脑点头才开数据口。题目与题集双向交换，收前先看新增、重复和冲突。

备份与恢复

整库导出 ZIP，含题目、原图、解答、自定义知识点与题集版式；导入时校验后再合并。不含 API Key。

a2 + b2 = c2

正文与选项用本地 KaTeX 排版，\(x^2\) 与 $x^2$ 都收。公式跟着题目走，不靠截图凑。

五步，打出第一张卷子

  1. 01

    装上来

    Windows 下 zip 完整解压，运行 Matheca.exe，DLL 与 resources/ 要一起留着。Android 装 APK；覆盖安装要求包名与签名一致。

    Windows x64 · Android 8.0+
  2. 02

    配接口（可跳过）

    在「题目识别与接口」填 HTTPS 地址、API Key 和支持图片输入的模型名，保存后测试。不配也能手动录题、整理和导出。

    可选
  3. 03

    收题

    拍照或导入 PDF。跨页照片按页码顺序放在同一批；手机上单份 PDF 最多 20 页，单个文件不超过 50 MB。

    照片 · PDF · 手动
  4. 04

    校对

    打开待校对题，对着原图改题干、插图和图片选项，补上年级与知识点，点「已校对」。

    人工操作
  5. 05

    组卷导出

    新建题集，选题、排序，设版式，导出 PDF 或 Word。AI 解答不会自动进练习文档，要放进去得自己选。

    A4 · PDF · DOCX

手机和电脑怎么对上

局域网
  1. 两台设备接进同一个能互访的局域网，桌面右下角加号打开「手机联动」。
  2. 手机扫二维码或粘贴完整连接地址，核对两端核对码，在电脑上允许。
  3. 在「选择资料」勾题目与题集，接收方校验后预览新增、重复与冲突，再确认。

配对凭证 15 分钟有效，一次连一台手机。这是手动交换：没有账户云同步，也没有后台自动同步。

也说说它做不到的

  • 1

    识别要联网，接口是你自己的

    图片会发往你配置的服务；接口调用可能产生服务费。请自己挑可信的服务商。

  • 2

    识别不等于校对完

    复杂公式、跨栏排版、几何图和题目完整性仍需人工确认。草稿的价值在于省了打字，不在于替你判断。

  • 3

    手机只走局域网

    不在同一网络就换不了题。没有账号体系，也没有云端题库，所以两端不会自动对齐。

  • 4

    数据在本机，删了就没了

    卸载会清掉应用私有数据。换机器或重装前，先在「题库备份」导出一份完整 ZIP。
