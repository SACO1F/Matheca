# Matheca Windows 桌面版

高中数学本地题库、校对与题集导出工具，使用 Electron、React、TypeScript 和 SQLite。界面固定浅色，可选石墨、雾蓝、陶土和梅紫强调色；本文说明 Windows 当前能力，Android App 位于同一仓库的 `app/`，两个平台分别构建。

## 手机联动第三阶段（Android 0.24.0）

Android 0.25.0 完成联动界面的视觉与动效统一：手机的题库、题集、选题及联动资料选择共用完整题卡，长题干不裁切、图片可换行；资料选择复用题集卡并固定底部选择数量和操作。桌面联动沿用工作台控件、主题色、题集行和题目渲染，所选题目显示完整正文、公式及图片，支持紧凑窗口和减少动态效果。

首次扫码并由电脑允许后，可在手机点击“记住这台电脑”。下次先在电脑开启“手机联动”，手机从“已配对电脑”再次连接；电脑关闭联动时不开放连接。地址或端口变化时重新扫码。电脑面板的“已配对手机”可移除配对并立即撤销访问；手机的“移除本机记录”只清除此手机保存的电脑凭证。

两端选择资料后，可选择“仅发送与对端不同的资料”。手机端选项为“仅加入与电脑不同的资料”；电脑端发送前在手机点击“检查连接”，更新内容摘要。相同内容跳过；题集结构或排版变化时传输该题集及全部关联题目。收到资料仍需预览和确认，冲突保留／替换／另存副本，不传播删除，不自动调用 AI。内容摘要包含原图、插图、选项位置与宽度、解答、题集顺序和排版；额外知识点差异可能导致保守地再次发送。

这是局域网的手动增量交换。手机联动页打开时刷新摘要；没有跨网络账号服务或系统后台自动同步。原有主题、原生图片编辑与 PDF／Word 导出沿用合并基线。

## 运行与快速开始

完整解压 Matheca-win32-x64-0.1.0.zip，运行文件夹中的 Matheca.exe。保留 resources、DLL 等运行资源，不要只复制 EXE。

构建输出到 releases/v版本号/构建时间/，同时保留完整应用目录、make/zip/win32/x64/ 下的 ZIP 和 SHA256SUMS.txt。最新完整路径见 releases/latest.txt。

新安装的正常题库在 %APPDATA%\Matheca（已有旧版题库时继续使用原目录，不搬移数据），与 EXE 目录分开。换解压目录不会迁移题库；跨机器移动数据使用设置中的 Windows ZIP 备份与导入。

1. 首次可使用三道示例题，或从右下角加号手动录入。手动题先作为未保存草稿，离开或保存时询问；空白题不留在题库。
2. 识别前在“设置与备份 → 题目识别与接口”填写地址、API Key、支持图片的模型名，保存并测试。该区域保留独立“图文配置教学”；简短说明中没有重复教程入口。
3. 加号可导入图片/PDF、截图；也可把文件或图片拖到窗口，识别结果先保存为待校对。“手机联动”可扫码接收照片、查看本次识别状态，并将导出的 PDF／Word 发送回手机。
4. 点击题卡展开：左侧是标签、题干预览、题干编辑与其他字段，右侧是原图。点击关闭按钮或题干预览保存并收起，核对后确认已校对并自动返回原题库或题集。
5. 点击“加入题集”，选择已有题集或创建。题集内可继续选题、移除、排序、设置留白，预览后导出。

手动录入、检索、校对、公式渲染和 PDF/Word 导出可离线使用；识别和 AI 解题需要自行配置的联网接口。

## 题库与校对

- 固定图标栏包含题库、题集、知识点、任务、历史、设置；激活仅图标轮廓着色。标题栏提供前进/后退、题库侧边栏开关和最近历史。
- 右下角加号沿用悬浮样式，不固定占用页面底部高度。题库与已选题目列表末尾预留 128px 可滚动空白，滑到底后可继续向下滚动一段，让最后一张题卡的操作按钮避开加号。
- 悬浮题库图标预览知识点树，点击切换题库；标题栏按钮控制常驻侧边栏。布局支持最小窗口与减少动态效果。
- 题卡为纵向列表、加粗题干，年级/难度/知识点标签可筛选。另有搜索、题型、校对状态、收藏筛选。
- 校对不显示题目标题输入框，不提供独立公式校对；LaTeX 在题干原位置渲染。
- 原图可滚轮/键盘缩放、拖动、适应窗口；“提取图形”为手动框选，保持缩放，不自动判断图形边界。
- 提取图形可放在题干或 A/B/C/D 选项，可单图调宽、统一选项图片宽度。卡片、预览、PDF、Word 与 Windows 备份包含已保存图形。
- 识别支持跨页续题和不完整提示，仍需人工核对。难度 1/2/3 分对应基础/进阶/挑战，仅作建议；AI 解答按段落显示。
- 未校对题显示“校对”，已校对题显示“修改”。确认、加入题集和删除的 toast 支持当前操作撤销；重启不保留撤销快照。
- 长按删除持续 1.2 秒，支持鼠标、空格或回车，提前松开/移出/失焦取消。

## 题集与导出

题集分为题集列表、文档设置、已选题目三列。“创建题集”位于第一栏题集列表下方；题集较多时列表独立滚动，创建按钮保持可见。已选题卡标签不筛选，卡片本身只选中；点击校对/修改进入编辑并直接返回题集。

PDF/Word 默认 A4，支持主标题、说明、时间、满分、顺序、每题留白和题前另起一页。默认留白：选择/填空 0mm，计算 30mm，证明/解答 50mm；可逐题设为 0–160mm。

预览使用 PDF 渲染；Word 预览是参考，实际 Word/WPS 可能重新分页。当前 Word 公式以图片输出，不保证原生可编辑。含待校对题导出前会提示。

## 数据安全与限制

Android 0.23.0 的联动题库交换使用桌面标准 ZIP；手机本地完整备份继续兼容旧 Android 的图片附件格式，不应混同为电脑交换包。Android App 的离线待传队列和局域网题库交换位于“我的 → 连接电脑”，不提供账户或跨网络自动同步。

## 手机联动（第一、二阶段）

1. 手机与电脑连接能互相访问的同一局域网，在右下角加号选择“手机联动”，用手机浏览器扫描二维码。
2. 核对手机与电脑显示的六位核对码，在电脑点击“允许连接”。未确认的手机不能上传、读取照片或下载文档。
3. 手机拍照或从相册选图，预览、移除、调整顺序后发送。失败可重试；照片已到电脑但回执丢失时，页面会自动核对接收记录，避免重复提交。
4. 在电脑“收到的照片”中确认并点击“开始识别”。手机“本次识别”和电脑同名页签可查看等待、处理、完成、部分完成、失败或暂停状态；失败后在电脑任务页继续处理。
5. 收起联动面板可继续保持连接，方便校对、组卷和导出。在题集中导出 PDF／Word 后，点击“发送到手机”，再点击“发送最近导出的文档”。手机在“电脑发来的文件”中下载，通过“保存／打开文件”交给系统查看或分享。
6. 不再使用时点击“结束连接”；连接也会在 15 分钟到期后失效。结束、到期或退出应用均停止收发，旧链接失效。收起面板或按 Esc 仅隐藏面板。

照片每批最多 20 张，单张最多 50 MB、合计最多 200 MB，支持 JPEG、PNG、WebP、HEIC/HEIF。每次连接最多接收 400 次新上传、准备 10 份回传文档，每份文档不超过 100 MB。文件以发送时的临时副本传输，原导出文件后续修改不影响该副本。仅可回传本次应用运行中导出的文档，不开放任意本地文件下载。

未识别照片保存在电脑，暂停或重启后可继续；手机刷新后可以查看电脑已接收的待识别照片。未发送的照片仅存在当前页面，刷新或关闭前请先发送。本次识别记录和文档下载列表仅属于当前临时连接，新连接需重新准备文件。第一阶段每次连接支持一台手机，换手机请结束后重新开启。

相机入口由浏览器与手机系统决定，可退回相册选图；没有网页实时取景和自动裁边。不需要安装 Android App，Android App 已支持局域网手动题库交换，跨网络访问尚未开放。Windows 若询问网络权限，请允许专用网络；校园 Wi-Fi 设备隔离可能阻止连接。

## 开发与统一验证

使用 Node 22、24 或 26 及以上，在 desktop/ 执行：

```powershell
npm ci
npm run verify
npm run format:check
npm run make:portable
npm run test:portable
npm run test:portable:full
```

核心入口 test:portable，完整入口 test:portable:full。默认测试 releases/latest.txt 中的实际 EXE，也可使用 --exe 完整路径指定；加 --list 只列出脚本。

针对失败项复核可用 `npm run test:portable -- --only tree-ui`；多项以逗号分隔，原始失败报告保留。

入口串行运行，在 test-output/validation-时间-进程号/REPORT.md 中记录 EXE 哈希、系统/Node、各项退出码、耗时、日志及新数据目录。任一失败退出码非零，超时/中断停止后续测试。正常题库不会作为测试数据。

完整接口套件需要 OpenSSL 与装有 reportlab/Pillow 的 Python，使用 MATHECA_OPENSSL、MATHECA_QA_PYTHON 指定；部分旧专项仍采用 Git for Windows 默认 OpenSSL 路径。使用本地模拟服务，不使用用户正常 Key。

离线构建可将 MATHECA_ELECTRON_ZIP_DIR 指向缓存运行时 ZIP 所在目录。当前文件名为 electron-v44.7.0-win32-x64.zip；使用前按 node_modules/electron/checksums.json 核对 SHA256，不要用其他版本运行时拼接应用。

verify 包含 TypeScript/Vitest；没有 ESLint，format:check 只是格式检查。旧 scripts/ui.mjs 等历史交互不包含在当前统一套件。

src/domain 管理规则，src/main 管理 SQLite/文件/接口/任务/导出和临时手机接收，preload 提供受控 IPC，src/renderer 管理界面。题库单列采用自然 Flex 排版，移除了逐帧改写题卡宽度/滚动位置的测量动画；校对面板仅短暂透明度/位移动画，没有引入 Motion 或替换动画库。

图标与 React Bits 来源/许可在 assets/ant-design、assets/react-bits；发布包附 THIRD_PARTY_NOTICES.txt。

## Android 题目与题集交换

Android 0.23.0 在“我的 → 连接电脑”扫码，也可粘贴桌面“复制连接地址”得到的完整地址。Android 17 上首次连接需要允许局域网／附近设备权限。二维码与第一阶段共享，一次连接只允许一台客户端；从浏览器切换到 App 时请结束旧连接并重新扫码。

- 手机可以离线拍照、相册选图，或勾选已有题目与题集加入待传队列。队列保存在手机本机，发送成功后标为已送达，原资料仍保留供手动清理。
- 电脑在“手机联动 → 题库交换”查看待接收资料，预览新增、重复与冲突数量，再明确确认接收。接收的 ZIP 未确认前不写入题库。
- 电脑在同一页勾选题目或题集发送，Android 在“接收题库”下载、校验、预览后接收。选题集会携带其全部题目、题目顺序与排版设置。
- 同编号且内容不同的记录视为冲突。可保留本机、使用收到的版本，或把冲突另存为新题／题集；保留副本时相关题集会引用新副本。重复发送同一内容不会无限新增副本。
- 双方若在预览后修改本机数据，确认会拒绝旧预览，需重新检查。收到资料不触发识别／解题，也不传播删除。
- 题目、原图、PNG 插图、选项位置、宽度、题集留白与分页字段均以桌面格式保存。Android 将桌面插图和留白分页映射到原生编辑及导出流程；宽度元数据用于桌面回传，手机导出沿用其原生图片布局。

每份题库 ZIP 最多 512 MB；电脑最多保留 10 份待处理资料，手机待传队列最多 100 项、合计 512 MB。文档仍为每份 100 MB。图片接收回执跨连接／重启保留最近 5,000 条；长期设备管理与自动增量同步属于后续阶段。完整字段、验证方法与限制见 [第二阶段说明](../docs/MOBILE_LINK_PHASE2.md)。


## 统一项目基线（0.23.0）

唯一开发目录为 `D:/AI/Matheca`：`app/` 基于 `D:/AI/Mathector` 的用户修改版移植，`desktop/` 保留第一、二阶段 Windows 功能。Android 继承四种强调色、明暗模式、图片与选项图片编辑、题集留白分页、滑动选择和 PDF／Word 导出，不再沿用旧版 App 的导出限制。桌面传来的图片和布局映射到原生编辑与导出流程，图片宽度等桌面元数据保留用于回传。原生完整备份保留旧格式兼容，联动发送采用桌面标准 ZIP，明确校验数量和大小，不静默裁掉图片。Room schema 9 兼容两个旧版本分支；保留原包名与数据目录。
