# 悬浮快捷按钮与末尾滚动空间

日期：2026-10-15。

## 当前行为

按用户要求撤销 P0 首轮的固定底部操作区，恢复原来的圆形悬浮加号与位置：常规窗口距底部 26px，较窄窗口 22px；原有大小、配色、透明背景、阴影与菜单保持不变。

题库和题集已选题目列表底部增加至 128px 的可滚动空白。这段空间属于列表内容，不会缩短可见工作区：平常阅读时界面照常延伸到底部，滑到最后一题后还能继续向下滚动，让末题及其操作按钮完整露出、避开加号。

校对时仍隐藏快捷加号。打开题集局部选题面板或导出预览时临时隐藏加号，不改变相邻列高度。设置、任务等页面不再被全局 88px 预留区压缩。

## 实现与说明同步

- `src/renderer/style.css`：移除工作区底部 88px padding，恢复加号原位置，题库/题集题目列表末尾 padding 为 128px。
- `scripts/fab-scroll-ui.mjs`：新增真实 EXE 专项，验证正常/最小窗口、列表延伸到底部、末题避让、操作区可命中及选题面板布局稳定。
- `scripts/sidebar-performance-ui.mjs`：把原“列表视口始终在加号上方”的断言改为“列表到底后末题在加号上方”，保留 DPI、动画与性能检查。
- `scripts/validate-portable.mjs`：新增专项加入核心/完整套件，现在为核心 10 项、完整 22 项。
- 桌面 README 与开发计划同步；P0 文档保留当轮证据，并标注旧操作区方案已被替代。
