# Matheca Tauri Windows 便携版（第 9 阶段）

双击 Matheca.exe 启动。需要 Windows x64 和已安装的 Microsoft Edge WebView2。
保持完整目录；React、字体和浏览器资源已嵌入 EXE，无需 Node 或 Electron。

当前支持独立题库中的题目录入与编辑、收藏与校对、题集管理与排序、删除和撤销、知识点管理、历史记录、设置保存，以及关闭确认、后台运行和托盘恢复。现已接入图片/PDF/HEIC 导入、剪贴板图片、拖放文件、AI 识别与解题、双任务并发、暂停/继续及重启恢复。需要先在设置保存兼容 Chat Completions 的 HTTPS 多模态接口。现已接入题集预览、带结构标签的 PDF 导出、Word 文档导出及打开本次生成的文档。ZIP 题库备份、预览和合并恢复已开放；手机联动与交互截图已开放，帮助链接和配置复制已接入。

默认使用 `%LOCALAPPDATA%/MathecaTauriPreview` 独立资料目录。可以从空题库开始录入，或通过顶部“复制原版题库”选择原版 Matheca/Mathector 的资料目录。复制只允许导入到没有题目、题集、自定义知识点、任务和密钥的独立题库，避免覆盖已有内容。原版与独立题库相互独立；同一题库不能同时在两边编辑后自动合并。

复制使用稳定的数据库/WAL 快照并校验原图，复制成功后会重建原图路径及有效解答指纹。缺失原图会明确提示。旧密钥能在当前 Windows 用户下读取时会转换为新的 Windows 保护格式；无法读取时保留加密资料并提示重新配置。不会发送网络请求或显示密钥明文。

验证时可以为当前进程设置绝对路径 `MATHECA_TEST_DATA`，指向独立测试目录。程序创建或升级该目录下的 library.sqlite，设置以 SQLite 为准；WebView2 缓存保存在 webview-profile 子目录。不能用正常资料库作为测试目录。

首次接管已有数据库前会在 backups/ 留存 SQLite 快照。已知旧结构可升级，较新版本或损坏结构会拒绝写入。复制失败会回滚数据库和本次复制的文件；启动时可清理明确属于未提交迁移的临时资源。备份数据库可供恢复验证，图像文件仍需与资料目录一起保留；完整 ZIP 备份恢复已在第 6 阶段接入。

关闭窗口可以选择取消、直接退出或后台运行。直接退出须由界面确认未保存内容处理完成；保存失败或取消时留在应用中。后台运行后可从托盘恢复或退出。

源码构建：在 desktop/ 执行 `npm run make:portable -- --tauri`。默认 `npm run make:portable` 生成 Tauri 版；`npm run make:portable -- --electron` 保留 Electron 回退构建。Rust 依赖由 Cargo.lock 固定；所有产物保存在新目录，不覆盖正在运行的版本。

第 6 阶段任务资料保存在 intake/，按完成页事务提交，继续任务跳过已完成页。退出会保存并暂停任务；重启后由用户点击继续，不会自动发起网络请求。已取消的请求或已修改题目的旧响应不能覆盖新题目。关闭窗口选择后台运行时继续处理。

一次最多 20 个文件，单文件最多 50 MiB、单份 PDF 最多 20 页；直接拖入内容最多 100 MiB。HTTP 响应最多 4 MiB，HTTPS 禁止重定向；连接/读取/总请求有超时。导入后的题目需要人工校对，AI 解答需要核对。缺少配置时不会启动导入。

保留 HEIC 原生 DLL、Visual C++ 运行库和 licenses/ 目录；详细版本与重建说明见 NATIVE_RUNTIME.md。源码打包还需设置 MATHECA_HEIF_BIN，指向经校验的 Windows x64 原生运行库目录。

第 6 阶段：题集页面可以预览 PDF/Word 内容，再确认导出。Word 使用高分辨率公式图片，保留公式替代文字，不是可编辑的 Word 原生公式；Word 最终分页随软件与字体变化。PDF 复用浏览器的 A4 排版，并要求 WebView2 输出结构标签；旧运行时不支持时会明确拒绝。

导出使用同一数据库快照，保留题集顺序、选项与配图归属、自定义图宽、分页设置和解答空间。未校对题目会先提示。生成失败、取消或目标文件锁定时保留旧文件，并清理本次临时文件；仅可打开本次生成且未被替换的 PDF/Word。单次最多 2000 道题、1500 个不同公式，输出最多 32 MiB；超出时请拆分题集。

第 6 阶段：在设置中选择“备份题库”保存 ZIP；“导入题库”或单独拖入 ZIP 可查看题目、题集、原图和缺图统计，再确认合并。与原版 Windows 备份格式兼容，支持 Matheca/Mathector v1。相同编号保留本地题目和题集，知识点按名称去重；不导入设置、API Key 和运行中任务。导入原图保存于 restored/，请与 library.sqlite 一起保留。

ZIP 和解压总量最多 512 MiB，清单最多 32 MiB，单张原图最多 50 MiB；拒绝路径穿越、重复条目、加密、CRC 错误、原图哈希不符和多余文件。确认前只处理独立临时副本，确认时重新验证；失败回滚数据库并清理本次原图，取消不改题库。崩溃后仅清理有应用标记且不被使用的未提交目录。

第 7 阶段：点击右下角“＋”，选择“手机联动”，电脑与手机连接同一局域网后扫码，核对连接码并在电脑批准。连接有效期为 15 分钟。收起面板可继续接收；“结束连接”、过期和退出应用会停止收发，旧连接与下载链接失效。重启应用不会自动监听网络。

照片先进入收件箱，电脑确认后才交给现有 AI 识别队列；支持 JPEG、PNG、WebP 和 HEIC，每张最多 50 MiB，每批最多 20 张、合计 200 MiB。同时最多接收 2 张。重复上传使用回执去重，未确认照片可跨重启保留。手机接收、配对凭据哈希和回执保存在独立题库 SQLite 中，照片在 mobile-inbox/；请与题库一同保留。

支持记住或移除配对手机、识别进度、发送本次生成且未变化的 PDF/Word、发送所选题目/题集和增量 ZIP。手机题库资料需要在电脑预览后选择保留本机、替换或另存副本；本机题库变化后须重新预览，导入回执与题目同事务提交。替换会停止相关旧解题任务。仅在主动开启期间监听 IPv4；不自动更改 Windows 防火墙设置。

第 8 阶段：题库页面右下角“＋”→“截图导入”，先隐藏工作台再冻结显示器画面。拖动框选题目，点击“识别此截图”或按 Enter 确认；Esc、取消或关闭选区窗口返回工作台，不建立识别任务。右键或“重新框选”可重选。每次选择一个显示器中的区域，最小 8×8 个界面像素；多显示器分别提供选区窗口，任一取消会结束本次截图。

截图使用 Windows GDI 和独立选区窗口，原始全屏图只在本次截图期间保留在内存中，确认后仅把裁剪结果复制到资料目录，交给现有 AI 识别队列。请先保存有效 AI 配置；截图不会操作系统剪贴板。显示器总原始图像最多 256 MiB，编码图合计最多 128 MiB，单图最多 50 MiB，最多 8 个显示器；等待选区超过 5 分钟会取消。

全部 53 个业务请求频道已接入。默认资料目录继续沿用 MathecaTauriPreview，保留已有迁移版资料；原版题库仍需按需复制或 ZIP 合并，不自动覆盖。使用 Windows x64 与系统 WebView2；复杂多屏缩放、HDR、受保护视频、远程桌面和实体手机网络仍需对应环境验收。

开发验收：`npm run test:portable` 默认选择最新 Tauri 成品并执行截图、数据、备份和导出检查；`npm run test:portable -- --suite full` 增加本地模拟 HTTPS 任务和手机浏览器检查。可以用 `--exe` 指定解压后的 EXE；指定 Electron 成品时自动使用原有 Electron 套件。旧库原生文件选择器验收单独运行 `node scripts/tauri-phase8-migration-ui.mjs`，需要在对话框中选择脚本生成的合成资料目录。

第 9 阶段交付：便携目录新增 PORTABLE_FILES.sha256，逐一列出 EXE、DLL、说明和许可文件的 SHA256。构建时检查 Windows x64 架构、完整运行资源，并拒绝混入题库、缓存、调试文件及 Node/Electron 运行时。请解压到新的完整目录后运行，不要覆盖正在运行的旧版本。复制便携目录不会搬移题库；题库仍存放在上述独立资料目录，迁移或换电脑前使用 ZIP 备份。

默认成品验收新增运行文件清单及 ZIP 内容一致性检查，并检查四种主题、接口草稿保留、历史分页和最近五次操作、字体与原图、紧凑/宽屏视口、减少动态效果、无效拖放反馈和重启持久化。正式交付范围是 Windows x64 便携版；本包未做代码签名，不包含自动更新服务。物理混合 DPI、HDR、远程桌面及实体手机网络的限制仍以本说明为准。
