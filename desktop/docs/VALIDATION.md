# Mathector Windows 0.1.0 验证记录

> 本文是历史记录。当前使用方式见 [桌面 README](../README.md)，本轮开发与验证见 [P0 验收记录](P0_STABILIZATION.md)。旧测试数量与界面描述不代表当前版本。

验证日期：2026-10-09。源码依据 Android 0.21.0 / Git 提交 `4d12b537405d7578211ce090a56564809a8f1100`。本记录区分程序实测、模拟故障与缺少环境的检查，不把格式测试计为 Android 应用实际互导。

## 环境

- Windows 11 家庭版中文版，64 位，系统版本 10.0.26300。
- Word 2021，WINWORD.EXE 产品版本 16.0.14326.20454。
- Electron 44.7.0 / Chromium 152，React 19、TypeScript 5.9、better-sqlite3 13.0.3。
- Node.js 24.19.0 / 25.8.1 执行本地构建；推荐其他开发者使用 Node 24 LTS。
- 真实 API Key 未提供。网络链路使用本机 HTTPS Chat Completions 测试服务及临时测试证书；没有关闭 TLS 校验。

## 重跑与证据

从 `desktop/` 运行 `npm run verify`、生产 `npm run package`、`npm run test:e2e` 和 `npm run test:integration`。指定 `MATHECTOR_EXE` 可验证安装目录或解压目录的程序，`MATHECTOR_QA_PYTHON` 指向含 reportlab / Pillow 的 Python；可用 `MATHECTOR_HEIC_TEST` 传入额外 HEIC 样本。

本机生成证据位于 `desktop/test-output/`，不进入源码或发行包：`sample.pdf` / `sample.docx`、`stress.pdf` / `stress.docx`、Word 转换 PDF、逐页 PNG、工作台截图、集成测试各批次数据库、中文 PDF 转图及升级检查截图。HEIC 样本来自 libheif 官方仓库 `examples/example.heic`，只用于本机测试。

构建中曾发现 Forge 默认过滤规则漏带外部依赖、PDF 错误摘要遮住超页数提示以及缺少 PDF 中文资源的问题；均已修复，并以实际发行 EXE 重跑对应检查。当前源码没有已知测试失败。
