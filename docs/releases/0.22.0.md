# Matheca Android 0.22.0

发布日期：2026-10-19。Android 高中数学题集 App，最低 Android 8.0。

## 本次更新

Android 配色与桌面 Matheca 的实际实现对齐：默认石墨，另提供雾蓝、陶土、梅紫。进入“我的 → 外观”，可独立选择配色和白天／黑夜／跟随系统，选择立即生效并本地保存。

- 白天沿用桌面的中性灰白背景、石墨正文、浅灰题目卡片和中性年级／知识点标签；主操作、导航、筛选及焦点跟随强调色。已校对、警告、错误保持独立状态色。
- 黑夜保留 Android 现有能力，使用深灰阅读底与浅强调色，主要按钮配深色前景。桌面当前是浅色工作台，黑夜色板为 Android 适配。
- 顶部统计取消亮蓝渐变，继续等宽、紧凑、居中。题干、AI 解答及独立公式预览的文字改为中性色；公式错误也适配黑夜。
- 菜单使用区别于页面与卡片的中性底色，保留圆角、无黑色阴影边框。悬浮按钮跟随配色，保留轻微透明、模糊和回弹。应用图标和系统默认强调色改为石墨。
- 升级默认使用石墨，保留已有明暗模式、接口配置与题库。保留远端的 Matheca 统一命名和旧包 ID 兼容；数据库仍为版本 4，ZIP 备份格式仍为版本 1，同时接受旧 Mathector 格式标识，外观偏好不进入题库备份。

颜色来源、完整角色与界面样例见 [配色规范](https://github.com/SACO1F/Matheca/blob/android-v0.22.0/docs/matheca-colors.md)。

## 验证

最终 APK、测试包、41 项单元测试和 lintDebug 构建完成。单元测试 0 失败／0 错误；Lint 0 错误、18 项警告。远端同仓库整合后的最终主构建 34 秒，随后仅重新构建截图和可达性测试包。

新增测试验证桌面颜色契约、八种主题组合的正文／辅助字／标签／主按钮／选中／错误等前景背景配对，普通文字至少 4.5:1，输入边界至少 3:1。白天菜单原先选用的较深浅灰使辅助字接近阈值，调整为桌面的 hover 灰后全部通过。

本次分批通过 7 个独立设备场景：

1. 在独立偏好中验证四种配色持久化、明暗模式独立、已有接口字段和自动解题偏好保留；未知配色回退石墨。
2. 实际设置页切换四种配色 × 两种明暗模式，检查单选语义、48 dp 选择区域、统计文字角色与实时显示；截图等待 KaTeX 字体、DOM 颜色、WebView 可见状态及绘制帧完成。
3. 验证两个主题下题集添加入口、年级菜单选择关闭，以及选题面板下滑收回。
4. 横屏下配色选项可滚动到达，完整露出于底部悬浮导航之上。
5. 约 375 dp 小屏、2.0 倍字号、系统窗口／转场／属性动画均关闭时，配色文字和选择区域保持可用。横屏也检查了相同配置，之后恢复原来的视口、字体及动画偏好。
6. 回归题库、编辑预览和 AI 解答中的行内与独立公式渲染、公式区域点击和预览不追加校对字段。
7. 回归紧凑文档设置保存、输入校验、题集添加按钮实际颜色跟随主题及文字对比度，保留添加与返回流程。

第一轮菜单检查使用 Espresso 返回时遇到原生弹出窗口焦点等待，其他三个新增场景通过；改为显式选择年级后验证菜单关闭，没有修改应用菜单逻辑。随后主题／菜单／公式／题集回归 4 项通过（53.560 秒）。最终 APK 的八组合矩阵专项通过（24.899 秒），字体与横屏专项 2 项通过（10.332 秒）。

共收集 14 张当前版本截图，公开 6 张使用临时数学题与应用示例的界面图。原先的公式加载过渡帧由等待实际绘制后的最终截图替换。本轮不重新生成历史 PDF／DOCX 样张，不调用真实识别服务，不操作真实手机。设备操作限定为 emulator-5554，测试结束恢复外观设置并删除临时题目／题集。未完成厂商真机和平板矩阵；此前其他功能边界继续见 README。
