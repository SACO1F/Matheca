- [x] 保留接收预览、保留／替换／另存副本和已有幂等保护，不自动触发 AI，不传播全局删除。
- [x] 损坏的桌面配对记录不阻断题库启动；仅拒绝开启联动并提示保留记录文件处理。

## 使用

1. 电脑打开“手机联动”，手机首次扫码并在电脑允许。
2. 手机点击“记住这台电脑”。以后电脑开启联动后，手机在“已配对电脑”点“再次连接”。同一电脑重新扫码后会更新已保存地址。
3. 手机发送：在“选择资料”勾选“仅加入与电脑不同的资料”，选择题目／题集，加入待传队列，再在“连接与待传”发送。全部发送模式仍支持离线排队；增量比较需要当前连接。
4. 电脑发送：手机先点“检查连接”，电脑在“题库交换”选择“仅发送与手机不同的资料”，选择资料后发送。相同内容提示无需发送。
5. 对端下载／收到后预览并确认；冲突由用户选择处理。移除题集内条目会随该题集结构更新，删除题目本身不会自动从另一端删除。
