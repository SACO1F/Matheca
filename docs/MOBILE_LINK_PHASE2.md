# 手机联动第二阶段：以桌面格式为标准

> 当前交付已更新为以用户 Mathector 修改版为基线的 Android 0.23.0 / schema 9，详见 [项目合并记录](PROJECT_MERGE.md)。下文 0.22.0／0.22.1 和旧格式限制为历史记录；当前原生图片编辑、含图片 PDF／Word 导出与完整备份均保留，桌面交换采用单独的格式桥接。

实现日期：2026-10-20。Windows Electron 与 Android 0.22.0 通过同一局域网临时连接收发资料，也可使用题库 ZIP 手动互导。本阶段是用户明确选择对象、确认接收的双向交换，不是自动云同步。

- [x] 照片与所选题目／题集可先加入本机离线队列，重启后继续，支持预览、排序、移除、失败重试与手动清理。

## 字段标准

| 内容 | 桌面标准与 Android 适配 |
| --- | --- |
| 题目 | 保留编号、标题、题干／子题、独立公式、分类、知识点、收藏、校对和示例状态 |
| 时间 | 清单中的创建时间为有符号 64 位整数；Windows 内部字符串经 lossless-json 转换，Android 使用 Long，避免大整数精度丢失 |
| 原图 | 清单引用 `sources/内容哈希.扩展名`；验证 SHA256、CRC、大小与关联，接收后映射新的本机路径 |
| 插图 | 保留 `figures` 的 PNG data URI；每题最多 6 张，单图及总文字大小沿用桌面限制 |
| 插图排版 | 保留 `figureWidths` 与 `figurePlacements`，位置为题干或 A/B/C/D；手机可查看带位置说明的图片 |
| 解答 | 保存已有文字、公式、错误及 `solutionCurrent`；接收后按本机内容指纹重新关联，不发起生成任务 |
| 题集 | 保留编号、名称、顺序、主标题、说明、时间与满分 |
| 留白与分页 | 保留 `questionLayout` 的 `answerSpaceMm` 与 `pageBreakBefore`，副本关联同步重映射 |
| 知识点 | 保留自定义名称和分组；同名项沿用本机已有分组，新增项经过高中词表校验 |
| 排除项 | 不传 API Key、接口配置、本机路径、主题偏好、后台任务或设备配对密钥 |

旧 Android 备份没有插图与单题排版字段时，以空插图和默认排版兼容读取。为避免旧版本丢弃新字段，手机应升级至 0.22.0 后再做双向往返。

## 操作流程

1. 电脑右下角“＋ → 手机联动”。手机打开“我的 → 连接电脑”，在 App 内扫码；或从电脑复制完整连接地址粘贴。
2. 允许必要的局域网／附近设备权限，双方核对六位码，在电脑允许连接。
3. 手机在“连接与待传”拍照／选图，或在“选择资料”勾选题目／题集加入队列；离线时也可完成这些步骤。
4. 连接后明确发送待传内容。照片进入电脑待识别区，资料包进入“题库交换”；两者均由电脑再次确认才处理。
5. 电脑向手机发送时，在“题库交换”勾选题目或题集。手机进入“接收题库 → 下载并预览”，选择冲突处理方式并确认。
6. 收到的题目可离线查看和编辑；选择后再次加入队列即可回传。完成后结束连接，已收到的本机资料继续保留。

## 限制与后续

- 一次临时连接一台客户端、15 分钟有效，跨网络和长期配对尚未实现。从手机浏览器切换到 App 时需结束旧连接并重新扫码。
- 照片仍为每批 20 张、单张 50 MB、每批 200 MB。题库 ZIP 每份最多 512 MB；文档每份 100 MB；同次连接最多准备 10 份回传文件。
- 手机队列最多 100 项、合计 512 MB，已送达项目保留到手动清理；电脑最多 10 份待处理 ZIP。不要卸载应用代替清理，卸载仍会删除本机队列。
- 图片回执最近 5,000 条跨连接／进程重启保留。题库接收确认另写入数据库回执，避免崩溃后重做覆盖。
- 不自动判断哪台设备更新。两端同编号内容不同即提示冲突，用户选择替换或副本；阶段三再考虑共同版本基线与增量更新。
- Android 当前保留并展示桌面图片字段，但含桌面插图、留白或分页设置的题集应在电脑导出，再通过第一阶段回传 PDF／Word。手机会明确阻止使用旧导出器静默丢失内容。
- 局域网传输沿用第一阶段临时 HTTP，Android 客户端仅允许明确私有／回环 IPv4 地址；识别接口的 HTTPS 校验保持原规则。Android 17 的权限要求参考 [Android 官方说明](https://developer.android.google.cn/privacy-and-security/local-network-permission?hl=en)。

## 验证方法与边界

Windows 检查类型、单元测试、Electron 运行时数据交换专项，再执行正常便携版构建并启动新 EXE。Android 构建应用与测试 APK，执行单元测试、Lint 与指定设备测试。

实际协议验证通过 Android 17 模拟器和打包 Windows EXE 建立 TCP 连接，检查离线队列恢复、双向选择资料、原图／插图／排版／顺序／解答、大于 JavaScript 安全整数的时间戳、冲突副本与替换，并确认没有 AI 任务。模拟器通过 ADB 端口转发连接，保留生产 Host 校验，不将它描述成已通过物理 Wi-Fi 验收。

界面证据来自真实 Android 模拟器截图和打包桌面截图，覆盖明暗主题、离线队列、选择资料、接收预览与紧凑桌面。备份与旧版迁移设备测试单独记录。真实相机扫屏、厂商手机、实际局域网隔离／防火墙、Android 8.0 实机及大规模性能仍需扩大验证。
