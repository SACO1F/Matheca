# 手机联动传输与界面修复（2026-10-28）

## 问题与修复

- Android 报 `unexpected end of stream`。小合成题库能通过，但包含约 7.68 MB 原图的题库在真实 Android 客户端下载时稳定截断。
- Windows 的非阻塞监听器所接受的 socket 继承了非阻塞模式。原发送代码使用 `write_all`，当发送缓冲区被填满时得到 WSAEWOULDBLOCK 并结束响应，HTTP Content-Length 大于实际收到的数据。
- 在解析请求前明确设置工作 socket 为阻塞模式，保留读取、写入超时与取消关闭；文件发送总预算 600 秒，单次写入超时 30 秒。
- Android 对下载 IO 中断最多重新下载两次，每次从零写入临时文件。校验完整大小，最终失败清除临时文件并显示中文提示。鉴权、大小校验错误不重试。
- 电脑发送成功后切换到“发往手机”，明确提示手机打开“连接电脑 → 接收题库”下载、预览、确认。
- 左侧菜单增加“手机联动”。有待处理照片或待接收题库时显示主题色小点，全部处理后消失。
- Android 两处 SnackbarHost 统一为圆角悬浮 Toast，支持明暗主题、操作按钮、关闭按钮与无障碍播报。
- 我的题库四个筛选器复用题集选题页的 PickerFilter，保留空选项、筛选状态和禁用逻辑。

## 验证范围

测试使用隔离资料库和 Android 模拟器，通过 ADB TCP 转发连接实际 Windows EXE。未操作用户的正常题库，也未安装或操作连接中的实体手机。实体手机 Wi-Fi、扫码摄像头与具体路由器环境仍需用户环境确认。
