## 实现范围

题库右下角“＋”→“截图导入”：隐藏主窗口后冻结各显示器画面，拖动框选，Enter 或“识别此截图”提交，Esc、取消或关闭选区结束。右键及“重新框选”支持重选；一次只提交一个显示器中的区域。裁剪结果进入已有 AI 导入队列，沿用配置检查、取消、任务恢复和题库事务。

Windows GDI 读取采用线程级 DPI 感知、32 位自顶向下 DIB，并将 BGRX 转换为不透明 RGBA。RAII 恢复 GDI 对象与 DPI 上下文。每个显示器使用独立全屏选区窗口，保留物理坐标与像素映射。裁剪验证有限数值、最小 8×8 界面像素、边界及窗口尺寸/缩放一致性。多屏取消联动，重复截图请求被拒绝；错误、加载超时、选区超时和退出都清理窗口。

原始全屏图仅保留在本次会话内存中，确认后仅保存裁剪结果；不通过剪贴板中转。最多 8 个显示器，原始像素合计最多 256 MiB，编码图合计最多 128 MiB，单图最多 50 MiB。加载等待 25 秒，选区等待 5 分钟。选区窗口只获授权调用四个截图命令，不能调用工作台、文件操作或渲染 worker。主窗口关闭期间先取消截图，再执行已有退出/后台策略，避免截图结束时错误恢复后台窗口。

帮助入口改为前后端共享的固定配置。Rust 只接受固定键，打开经过限制的 HTTPS 地址或复制固定配置值；任意 URL、路径和未知键被拒绝。沿用原版链接与配置内容。

`desktop/scripts/portable.mjs` 默认构建 Tauri，`--tauri` 保持兼容，`--electron` 构建回退版。每次使用新的输出目录。便携验证脚本默认选择 latest-tauri.txt，根据成品判断运行 Tauri 或 Electron 套件，可用 --exe 指定 ZIP 解压后的成品。完整目录保留 HEIC/Visual C++ 运行库和许可；运行无需 Node 或 Electron，需要系统 WebView2。

默认资料目录继续使用 `%LOCALAPPDATA%/MathecaTauriPreview`，保留已有迁移数据。原版与迁移版题库独立，通过“复制原版题库”或 ZIP 合并转入。本阶段没有改动用户正常题库。

## 验证边界与保留的失败记录

最终截图端到端测试使用合成显示器图案，不读取用户桌面。GDI 读取代码通过私有内存 DC 测试；真实混合 DPI、多屏硬件、HDR、受保护视频和远程桌面尚未逐项验收。手机验证使用隔离浏览器及回环协议客户端，没有实体手机跨 Wi-Fi 验收。帮助打开/复制使用隔离操作记录验证，未改用户剪贴板或打开默认浏览器。旧库复制的原生文件选择器本阶段未在最终包重新手动执行；迁移逻辑继续由已有测试覆盖。

早期候选成品的原生拖动与 Esc 取消通过，记录在 tauri-phase8-1793099101280/REPORT.md。最终包补充人工取消测试中，程序实际返回已确认而脚本期待取消，断言失败；没有计入通过，也不能据此声称最终包的人工 Esc/Alt+F4 验收通过。最终包自动化取消、后台关闭和活动选区退出检查全部通过。上述结果分别保留，避免混用候选包与最终包证据。

测试仅清理自身启动的进程，未终止用户原有应用；未改正常题库、系统证书库或防火墙。没有使用正常资料库充当测试输入。
