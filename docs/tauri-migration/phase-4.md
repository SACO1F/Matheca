# Tauri 迁移第 4 阶段：AI、任务与资料导入

日期：2026-10-27（北京时间）

本阶段在 React 工作台上接入 Rust 网络和任务后端。53 个业务请求频道中已开放 29 个，剩余 24 个继续保留明确的未开放错误；DesktopAPI 的 57 个方法保持兼容。

## 本阶段行为

| 范围       | 实现                                                                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 图片接口   | Rust reqwest 调用 HTTPS Chat Completions，读取 Windows 加密密钥；密钥不传给前端或本地处理窗口                                  |
| 请求约束   | 禁止 HTTP、账号参数和重定向；连接 20 秒、读取 120 秒、总请求 150 秒超时；响应最多 4 MiB；错误提示不回显服务响应体              |
| 导入入口   | 原生多文件选择、原生拖放、浏览器 File 分块上传、Windows PNG/DIB 剪贴板；原图复制到独立资料目录                                 |
| 格式与限制 | JPG/JPEG/PNG/WebP/HEIC/HEIF/PDF；最多 20 个文件，单文件 50 MiB，单份 PDF 20 页，直接拖入总量 100 MiB；图片有尺寸与解码内存限制 |
| PDF 和跨页 | 隐藏本地 WebView 运行已有 PDF.js 与图片拼接逻辑；复用原有跨页提示词、补页规则和结果校验，目标页之外开始的题目不重复录入        |
| AI 解题    | 复用原有解题提示词和结果校验；题目指纹、当前任务和运行编号共同约束写回；保留用户后续修改的难度                                 |
| 任务       | 两个任务并发、队列调度、暂停/继续、失败页重试、完成页跳过、自动解题、状态与历史事件                                            |
| 事务       | 题目和完成页标记同一事务提交，确定性题目编号避免重试重复；失败事务不留下半页题目                                               |
| 退出与恢复 | 关闭为后台运行时继续任务；直接退出先暂停并保存进度，再取消请求；强制中断后重启将未完成任务转为暂停，等待用户继续               |
| 并发保护   | 每份资料目录只有一个任务调度实例；其他窗口的题目修改或关闭自动解题会在同一数据库事务内使旧任务失效                             |
| 原图和配图 | Rust 处理框选裁剪；HEIC 经动态原生库转换；旧题库保留的 HEIC 原图可在受控协议中显示及提取                                       |
| 临时资源   | 分块上传、复制失败和启动恢复按应用标记清理；保留已被题目或任务引用的原图以及无标记目录                                         |

网络和任务执行全部在 Rust 中完成，没有 Node/Electron 业务辅助进程。隐藏本地 WebView 只承担图片/PDF 与既有领域规则处理，仅有 worker_reply 权限；没有题库命令、文件系统权限或密钥。主窗口也不能提交 worker 回复。数据经过 Rust 校验和事务后才保存。

- Windows 原生选择器实际选择模拟图片后完成识别。
- 工作台题目与任务页正常渲染。

## 资料目录与使用

默认仍为 `%LOCALAPPDATA%/MathecaTauriPreview`。正常原版数据没有自动接管，复制入口沿用第 3 阶段空目标库限制。在设置中保存兼容 Chat Completions 的 HTTPS 多模态接口和模型、API Key，再选择图片/PDF，或拖入文件。识别结果应人工校对，AI 解答需要核对。失败或暂停的任务可在“任务”页面继续。

intake/ 保存任务原图与 PDF 页面，uploads/ 保存尚未提交的 File 分块；不要只搬运 library.sqlite 而丢弃这些资源。退出不会删除暂停任务的原图。复制旧库时，未完成任务转为暂停；原图路径变化后更新仍匹配原题的解题任务指纹，避免误判为题目修改。

完整便携目录包含动态 HEIC DLL、MSVC 运行库、许可文件、Rust 依赖清单及 NATIVE_RUNTIME.md。React、PDF.js、字体和本地处理页面嵌入 EXE，运行需要 WebView2。私有企业 CA 可通过进程环境 MATHECA_HTTPS_CA 指向 PEM CA；默认使用系统信任，始终验证主机名，不关闭 TLS 校验。

## 边界与后续阶段

交互截图选区按第 8 阶段接入；ZIP 题库需要第 6 阶段的预览、校验、冲突处理和恢复，当前明确拒绝。PDF/Word 导出属于第 5 阶段，手机传图属于第 7 阶段。本阶段导入 PDF 是读取资料，不包含导出能力。
