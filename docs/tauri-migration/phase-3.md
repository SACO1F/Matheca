# Tauri 迁移第 3 阶段：Rust 数据层与旧库复制

日期：2026-10-27（北京时间）

本阶段将正式 Tauri 工程从只读预览推进到可持久化编辑的独立题库。React 工作台及 DesktopAPI 的 57 个方法保持兼容；53 个请求频道中，21 个已接通，32 个后续迁移频道仍明确返回尚未开放。

## 原版资料复制

默认 Tauri 资料目录仍为 `%LOCALAPPDATA%/MathecaTauriPreview`。复制由用户手动选择原版 Matheca/Mathector 资料目录触发，不能覆盖已有题目、题集、自定义知识点、任务或密钥的目标库。

复制过程只通过文件读取访问源数据库、WAL 和回滚日志，前后校验文件内容哈希，在自己拥有的临时副本中打开 SQLite 并生成一致快照。随后复制数据库记录和引用的原图、任务图片、页面图片及批次目录，校验图片哈希并重新映射路径；有效解答指纹随路径更新。拒绝源目录之外的路径及符号链接/重解析点，限制单文件、总大小和文件数量。

旧设置、历史及待处理任务记录保留。旧 Electron 密钥可在当前 Windows 用户下解密时，转换为新的 DPAPI 格式；不能解密时保留加密资料并展示重新配置提示。迁移本身不请求 AI 服务。任务执行与恢复在后续阶段接入。

目标库写入在事务中完成，提交标记与数据同一事务提交。失败时回滚记录并清除本次拥有的复制资源；启动恢复只清理明确属于未提交批次的目录。首次接管和迁移前的 SQLite 快照保存在独立资料目录的 backups/，恢复验证已覆盖。数据库备份应与原图目录共同保留；完整 ZIP 备份恢复尚未接入。

## 当前边界

Tauri 版可用于本地题库编辑和复制验证。图片/PDF 导入、AI 识别与解题、文档导出、手机传图、完整 ZIP 备份恢复仍未迁移。旧库任务记录可保留，但当前不会启动。HEIC 转换与导入资源处理继续采用第 1 阶段验证结果推进。

本阶段没有切换默认分发：`npm run make:portable` 仍构建完整 Electron 版，`npm run make:portable -- --tauri` 构建阶段预览。所有版本输出到新目录，保留完整便携目录及 ZIP，不覆盖运行中的版本，不修改用户正常资料。
